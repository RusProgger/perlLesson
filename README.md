# perlLesson

Справочник и уроки по Perl для новичков.  

Репозиторий предназначен для изучения Perl с нуля, практики на ПК и закрепления пройденного материала. Содержит простые примеры, мини-проекты и практические задания.  

---

## Содержание репозитория

- `HelloWorld/` — Первый скрипт: вывод текста на экран  
- `GuessNumber/` — Игра «Угадай число»  
- `Variables/` — Примеры работы с переменными разных типов  
- `ArraysAndHashes/` — Работа с массивами и хэшами  
- `References/` — Ссылки на переменные и структуры данных  
- `OtherLessons/` — Разные полезные упражнения и практики  

---

## Как запускать скрипты

1. Убедитесь, что Perl установлен на вашем ПК:  
   - **Windows** — [Strawberry Perl](https://strawberryperl.com/)  
   - **Linux / macOS** — Perl обычно установлен или `sudo apt install perl` / `brew install perl`

2. Перейдите в папку с нужным проектом:

```bash
cd perlLesson/GuessNumber

```

3. Запустите скрипт:
- perl guess.pl
